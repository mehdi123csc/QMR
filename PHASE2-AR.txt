Qmr Store — المرحلة الثانية

المحتويات:
- تتبع الطلبات باستخدام رقم الطلب ورمز عشوائي خاص، مع تخزين بصمة SHA-256 للرمز فقط.
- تعرض صفحة التتبع حالة الطلب وتاريخه فقط؛ لا تعرض الاسم أو الهاتف أو العنوان أو المنتجات.
- ملف SQL جديد: supabase-phase2-tracking-security.sql

قبل النشر:
1. خذ نسخة احتياطية من ملفات GitHub وراجعها.
2. في Supabase SQL Editor شغّل supabase-phase2-tracking-security.sql بعد supabase-setup.sql وsupabase-global-upgrade.sql.
3. إذا نجح التنفيذ، ارفع ملفات المشروع المحدثة إلى GitHub.
4. اختبر طلبًا تجريبيًا جديدًا، واحفظ رقم الطلب ورمز التتبع اللذين يظهران مرة واحدة.
5. افتح قسم «تتبعي طلبك» واختبر الرمز الصحيح والخاطئ. لا تنشئ طلبات كثيرة ولا تحذف الطلبات القديمة.

مهم:
- الطلبات الموجودة قبل تشغيل هذا التحديث لن تملك رمز تتبع، وستبقى محفوظة دون تعديل.
- لا ترفع مفتاح service_role إلى GitHub؛ المفتاح المنشور في config.js يجب أن يكون publishable/anon فقط.
- هذه الملفات لم تُنشر تلقائيًا على الموقع المباشر.
